See `INTEREST.md`. Six checks — all must PASS for showcase rooms.

## Clarity table (teach rooms)

| Check | Pass | Fail |
|-------|------|------|
| Readable goal | Spawn sees door / key silhouette | Goal hidden unfairly |
| One new verb | Tester names the teach | Two competing teaches |
| Fair fail | Failure teaches the verb | Cheap / opaque death |
| Softlock | Reversible or taught undo | Softlock with no exit |
| Target time | ≤1.5× listed target | Feels like a slog on paper |
