# Interest rubric — what makes a room worth playing

This gauntlet judges **room design**, not a playable build.
A room PASSes only if it is **interesting** under these checks.

## Six interest checks

| # | Check | PASS | FAIL (boring / muddy) |
|---|--------|------|------------------------|
| 1 | **One sentence idea** | You can name the puzzle in one line | “Just jump over stuff” / two competing ideas |
| 2 | **Visible lie** | First glance suggests a wrong plan; second glance shows the real one | Either trivial OR opaque with no fair read |
| 3 | **Verb tension** | Carrying / switching / timing changes what Mario *can’t* do | Verbs never conflict; no tradeoff |
| 4 | **Aha beat** | A single moment where the solve clicks | Grind until it works by accident |
| 5 | **Fair fail** | Death/reset teaches the idea | Cheap spikes, hidden hitboxes, softlocks |
| 6 | **Memorable silhouette** | You could sketch the room from memory | Generic corridor of platforms |

**Room PASS** = all six green.  
**Remix rooms** may reuse a verb if the *lie* or *tension* is new.

## Anti-patterns (instant FAIL)

- Tall empty ladder with door on top (T1-teach is OK as teach; not as showcase)
- Key left, door right, flat walk
- Switch next to the gate it opens with no spatial cost
- Enemy as only “interest”
- DK barrels with no other idea

## Critique loop (design only)

For each candidate room:

1. Write the **one-sentence idea**
2. Draw the ASCII / diagram
3. Label **lie → aha → fail**
4. Score the six checks
5. Revise or cut until PASS
6. Only then place it in a world sequence
