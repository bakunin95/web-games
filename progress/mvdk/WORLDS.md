# World sequence — Round 4 (design)

Curve shape per world: **teach → test → twist → rest → spike**.

Showcase rooms (`SHOWCASE.md`) are the interest spikes. Teach rooms (`ROOMS.md`) stay clarity-only.

## World 1 — Toy Factory (intro)

| Slot | Room | Role | Idea |
|------|------|------|------|
| 1-1 | T1 Ladder | teach | climb |
| 1-2 | T2 Key | teach | hands-full |
| 1-3 | T3 Switch | teach | cause → path |
| 1-4 | T4 Conveyor | teach | ride then jump |
| 1-5 | T2+T3 remix | test | switch then key |
| 1-6 | rest | rest | scenic climb, no new verb |
| 1-7 | **S1 Wrong balcony** | spike | drop commitment with key |

**Boss tease:** DK silhouette drops 1 barrel mid 1-7, then leaves (telegraph only — not the puzzle).

## World 2 — Girder Gardens (twist)

| Slot | Room | Role | Twist |
|------|------|------|-------|
| 2-1 | T5 Key + enemy | test | time past patrol |
| 2-2 | **S3 Belt prep** | twist | reverse belt *before* key |
| 2-3 | T6 Switch order | teach | sequence |
| 2-4 | **S2 Decoy door** | twist | commit switch + fake door |
| 2-5 | rest | rest | wide girders, no threat |
| 2-6 | **S5 Greedy keys** | spike | leave one key |
| 2-7 | **S7 Spring or softlock** | spike | “optional” spring is mandatory |

## World 3 — DK Rooftop (setpiece)

| Slot | Room | Role | Pressure |
|------|------|------|----------|
| 3-1 | T8 lite | teach | barrels, no key |
| 3-2 | **S4 Enemy step** | twist | enemy = platform |
| 3-3 | T8 | test | barrels + key (flat) |
| 3-4 | rest | rest | safe balcony beat |
| 3-5 | **S6 DK metronome** | spike | rhythm hold-switch |
| 3-6 | finale | spike | Mini-Mario under DK smash cycle (remix S6 beat) |

## Curve rules

- Never introduce 2 new verbs in one room
- Rest rooms every 4–5 levels
- Difficulty cliffs = FAIL Round 4
- DK pressure ramps; never first appearance as instant-death spam
- Showcase rooms carry the *interest*; teach rooms carry the *grammar*
